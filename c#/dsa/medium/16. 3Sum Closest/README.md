# 3Sum Closest (C#)

This folder contains a C# solution for the `3Sum Closest` problem along with a small reflection-based runner.

## Files

- `Solution.cs` - algorithm implementation
- `Program.cs` - test runner
- `ThreeSumClosest.csproj` - project file

## Run

```bash
cd "C:\Users\Sabelo Kama\Documents\VSCode\tutorials\c#\dsa\medium\16. 3Sum Closest"
dotnet build
dotnet run
```

## Notes

The runner covers several cases, including:
- matching the exact target early
- negative and positive values
- multiple candidate triplets
- boundary-style inputs
