# 3Sum (C#)

This folder contains a C# solution for the `3Sum` problem, along with a small reflection-based runner.

## Files

- `Solution.cs` - the algorithm implementation
- `Program.cs` - test runner
- `ThreeSum.csproj` - project file

## Run

```bash
cd "C:\Users\Sabelo Kama\Documents\VSCode\tutorials\c#\dsa\medium\15. 3Sum"
dotnet build
dotnet run
```

## Notes

The runner checks several cases, including:
- duplicate values
- no-solution inputs
- all-zero inputs
- multiple valid triplets
