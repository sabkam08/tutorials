# Integer to Roman

This folder contains a C# solution for LeetCode 12, plus a reflection-based `Program.cs` runner with a set of test cases.

## Run

```bash
cd "C:\Users\Sabelo Kama\Documents\VSCode\tutorials\c#\dsa\medium\12. Integer to Roman"
dotnet run
```

## Files

- `Solution.cs` - converts an integer to a Roman numeral
- `Program.cs` - runs multiple test cases and verifies the output
- `IntegerToRoman.csproj` - .NET console project file
